# Project Blueprint

## Overview

A simple Angular application.

## Features

*   Initial Angular project setup.
*   Deployment to a Firebase Hosting preview channel.
*   Deployment to the live Firebase Hosting channel.
*   Custom domain configuration.

## Current Plan

**Goal:** Deploy the application to a custom domain.

1.  **Configure Firebase MCP:** Updated `.idx/mcp.json` to resolve Firebase authentication issues.
2.  **Build Application:** Ran `ng build` to compile the Angular application.
3.  **Deploy to Preview Channel:** Deployed the application to a new preview channel named `dev`.
4.  **Deploy to Live Channel:** Deployed the application to the main Firebase Hosting channel.
5.  **Provide DNS Configuration:** Provided the necessary `A` records for custom domain setup.
